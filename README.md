# Alonso Chang — Portafolio

Sitio web personal de Alonso Chang, diseñador multimedia e ilustrador (Arica, Chile).

- `index.html` — sitio completo (plantilla, lógica y contenido)
- `support.js` — runtime que renderiza la página
- `img/` — imágenes locales
- `docs/handoff.md` — especificación de diseño

Ver en local: `python -m http.server 8000` y abrir http://localhost:8000
